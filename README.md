# «Что поесть» — лендинг Кристины Василиу (vas_kristi)

Живая версия: https://sergeykutedesign.github.io/KRV/ (GitHub Pages, ветка `landing-v1`, обновляется после каждого пуша).

Статичный сайт: `index.html` + `assets/`. Сборка не нужна — локально достаточно `python -m http.server 5173`.

## Позиционирование

- **Зачем приходят:** за фигурой.
- **Почему раньше не получалось:** не из-за силы воли, а из-за усталости каждый день решать «что поесть» → срывы.
- **Что продаём:** систему, которая убирает это решение: 1,5–2 часа у плиты — еда на 3 дня, КБЖУ и список продуктов готовы.
- **Главное сообщение:** «Забудь о вечном „Что поесть?“».

Правила текста (от дизайнера): человек смотрит лендинг 1–2 минуты. Блок — это «крючок + пояснение», подзаголовок — одно короткое предложение, не больше 3 строк. Цифры живут внутри преимуществ («60+ рационов»). Всё длинное — в FAQ.

## Сценарий страницы

1. **Hero.** Видео на весь экран → при скролле сжимается в карточку, по бокам выплывают стикеры (1,5 часа · −13 кг · 0 подсчётов · Десерты), карточка улетает вверх, за ней — «Представь: больше не нужно думать, что приготовить».
2. **«Дело не в силе воли»** — наезжает на hero. Сад: луг с маками, ромашками, космеями, базиликом и томатами, лианы по краям и сверху, падают лепестки. SVG рисуется кодом (`buildGarden` в `main.js`), растёт один раз, дальше покачивается на CSS.
3. **Как это работает** — 4 экрана сменяют друг друга, фото выезжают «шторкой».
4. **Почему работает** — 4 цветные панели наслаиваются; на телефоне — карусель.
5. **Калорийность 1400–1800** — табы живут в карточке под фото, фото, бейдж и таб меняются вместе; на телефоне фото листается свайпом.
6. **Ленты «паста ✦ пицца… / не диета»** — canvas: буквы едут вдоль кривой «змейкой», ускоряются от скорости скролла.
7. **Что внутри** — список под заголовком, фото пункта справа; на телефоне — карусель карточек.
8. **Кристина** — коротко + цифры (−13 кг, −15 кг у Макса, 4 600+, 180K).
9. **Отзывы** — 9 лучших (на телефоне 7) плывут поверх большого заголовка и тают у верхнего края. Все 24 — в боттом-шите «Читать все отзывы», в конце шита — кнопка доступа.
10. Тарифы. 11. Вопросы. 12. Финал + подвал.

## Механики

- **Сцены на `position: sticky`** (без GSAP-пинов): прогресс скролла управляет анимациями → всё одинаково вниз и вверх.
- **Наслаивание:** следующая секция со скруглённым верхом выезжает поверх предыдущей (`margin-top: -100svh`). Уходящий экран чуть уменьшается и гаснет, только когда новый закрыл ~40% экрана. **Без blur** — текст читается, пока блок на месте.
- **Кнопка «получить доступ»:** в hero её ведёт JS (под заголовком → центр видео-карточки → низ). Внизу экрана она привязана через CSS `bottom` (класс `is-docked`), поэтому едет вместе с панелью браузера (Яндекс, Chrome, Safari), а не «телепортируется» после resize. В блоке тарифов прячется — там свои кнопки. По нажатию раскрывается как iOS-виджет.
- **Карусели на телефоне** (`.hs`): карточка на всю ширину, зазор 4 px, тени по краям показывают, куда листать. Правило общее для всех горизонтальных списков.
- **Боттом-шиты** (меню, доступ, отзывы): ручка, закрытие свайпом вниз, крестик, Esc, клик по фону. Пока шит открыт, шапка на телефоне уезжает.
- **Прелоадер:** маскот прыгает на надпись «Что поесть» (Lobster), надпись «пишется», подпись «готовые рационы на 3 дня», минимум 2,3 с.
- **Типограф (JS):** неразрывные пробелы после предлогов и союзов, перед тире, между числом и единицей.

## Дизайн-система

- **Логотип:** маскот-ланчбокс + «Что поесть» шрифтом Lobster. Фавиконки и иконки — маскот (`assets/img/favicon*`, `icon-*.png`, `apple-touch-icon.png`).
- **Шрифты:** Lobster — логотип и заголовки (курсива нет, акценты цветом), Geist — текст. Файлы свои (`assets/fonts`, OFL), подмножества кириллица/латиница, Google Fonts не нужен.
- **Цвета:** молочный `#F7F5EC`, крем `#EEE9DA`, глубокий оливковый `#2E3520`, оливковый `#5E6A3A`, шалфей `#CBD0B2`, лайм `#DCE7A9`, терракота `#96583F`, чернила `#1D1B14`.

## Производительность

- Анимируются только `transform` и `opacity`; анимированного `filter: blur` нет нигде.
- Слои, которые уменьшаются при наезде следующего блока, заранее вынесены в отдельный слой (`will-change`) — растеризуются один раз.
- Фото шагов и карточек декодируются заранее (`img.decode()`), у больших фото есть `srcset` (720/1280).
- Ленты: одна canvas, лента рисуется в кэш один раз, каждый кадр — только ~150 букв из атласа, и только пока блок на экране.
- Lenis (плавный скролл) — только для колеса мыши; на тач-экранах родной скролл.
- Замер (headless Chrome, CPU замедлен в 2× на десктопе и в 4× на телефоне): было 18–22 fps в среднем и до 75% кадров с рывками в отдельных блоках; стало 44–57 fps почти во всех блоках.

Один `h1`, по `h2` на блок, у всех картинок есть `alt`.
Когда появится свой домен, замените `https://sergeykutedesign.github.io/KRV/` в `index.html`, `robots.txt` и `sitemap.xml`.

## Как добавить отзыв

Скрин → WebP шириной 640 px в `assets/img/reviews/`, затем `<figure class="rsheet__item">` в шит (`#all-reviews`). Чтобы показать на странице — ещё одна `<figure class="rv__item">` в `.rv` (`--c` — колонка 1–3, `--o` — сдвиг вниз, `--r` — наклон; `rv__item--desk` — только на десктопе).
