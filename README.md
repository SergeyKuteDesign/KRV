# «Что поесть» — лендинг Кристины Василиу (vas_kristi)

Живая версия: https://sergeykutedesign.github.io/KRV/ (GitHub Pages, ветка `landing-v1`, обновляется после каждого пуша).

Статичный сайт: `index.html` + `assets/`. Сборка не нужна — локально достаточно `python -m http.server 5173`.

## Позиционирование

- **Зачем приходят:** за фигурой.
- **Почему раньше не получалось:** не из-за силы воли, а из-за усталости каждый день решать «что поесть» → срывы.
- **Что продаём:** систему, которая убирает это решение: 2 часа у плиты — еда на 3 дня, КБЖУ и список продуктов готовы.
- **Главное сообщение:** «Худеть вкусно, готовить раз в три дня».

## Сценарий страницы

1. **Hero-сцена (как у Serein).** Видео на весь экран → при скролле сжимается в карточку, по бокам выплывают карточки-преимущества, в центре остаётся кнопка → карточка уходит вверх и открывает следующий заголовок.
2. «Дело не в силе воли» — следует за hero; по нижнему краю качаются лианы, трава и полевые цветы.
3. «Как это работает» — четыре шага сменяются при прокрутке.
4. «Почему худеют» — 4 цветные панели наслаиваются друг на друга (как serein investment-management); на телефоне — горизонтальная карусель.
5. Калорийность 1400–1800 — переключатель и фото выбранного рациона в одной карточке.
6. Ленты «паста ✦ пицца… / не диета».
7. «Что внутри» — список под заголовком, фото появляется в соседней колонке. На телефоне карточки листаются по горизонтали.
8. Кристина.
9. Отзывы — на десктопе карточки проходят поверх закреплённого заголовка, на телефоне листаются по горизонтали. Остальные отзывы открываются в нижней панели.
10. Тарифы. 11. Вопросы. 12. Финал + подвал.

## Механики

- **Сцены на `position: sticky`** (без GSAP-пинов): прогресс скролла управляет анимациями → всё работает одинаково вниз и вверх.
- **Наслаивание:** следующая секция со скруглённым верхом выезжает поверх предыдущей (`margin-top: -100vh`), предыдущая немного уменьшается по мере перекрытия.
- **CTA-док:** кнопка с маскотом появляется под заголовком hero, переезжает в центр видео-карточки, затем оседает внизу экрана и остаётся у видимого края экрана при изменении высоты окна браузера. По нажатию раскрывается как iOS-виджет (размер, радиус и цвет перетекают из кнопки в карточку и обратно).
- **Меню:** в шапке только логотип и кнопка; на десктопе меню вырастает из шапки по наведению.
- **Мобильные модалки:** боттом-шиты с ручкой, закрываются свайпом вниз; крестик справа сверху.
- **Прелоадер:** короткая заставка с маскотом и названием проекта.
- **Типограф (JS):** неразрывные пробелы после предлогов и союзов, перед тире, между числом и единицей.

## Дизайн-система

- **Логотип:** маскот из материалов проекта и надпись «Что поесть» шрифтом Lobster. Маскот используется и в фавиконке.
- **Шрифты:** Lobster для заголовков, Geist для основного текста и Noto Serif Display для акцентов.
- **Цвета:** молочный `#F7F5EC`, крем `#EEE9DA`, глубокий оливковый `#2E3520`, оливковый `#5E6A3A`, шалфей `#CBD0B2`, лайм `#DCE7A9`, терракота `#96583F`, чернила `#1D1B14`.

## Производительность

- Первый кадр hero отрисовывается из WebP-постера. Видео загружается в видимой секции: 960×720 на десктопе, 544×966 на телефоне.
- Текст движется по изгибу лент в заранее отрисованном ролике (`tools/ribbon-render.js`). Ролик загружается и проигрывается при появлении секции на экране.
- Картинки WebP, `loading="lazy"`, `decoding="async"`; без `backdrop-filter` и полноэкранных фильтров в hero.
- Нативная прокрутка. Анимации вне экрана останавливаются, для системной настройки уменьшенного движения доступны статичные сцены.

## SEO

title/description, canonical, Open Graph + Twitter (`assets/img/share-card.jpg`, 1200×630), фавиконки и `site.webmanifest`, `robots.txt`, `sitemap.xml`, JSON-LD (`WebSite`, `Person`, `Product` с двумя `Offer`, `FAQPage`). Один `h1`, по `h2` на блок, у всех картинок есть `alt`.
Когда появится свой домен, замените `https://sergeykutedesign.github.io/KRV/` в `index.html`, `robots.txt` и `sitemap.xml`.

## Что ещё нужно от Кристины

- фото «до/после» или анализы участниц — под них можно добавить блок результатов между «Почему худеют» и «Кристиной»;
- оригиналы новых отзывов можно добавить в `assets/img/reviews/` и связать с карточками архива в `index.html`.
