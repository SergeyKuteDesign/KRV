# «Что поесть» — лендинг Кристины Василиу (vas_kristi)

Живая версия: https://sergeykutedesign.github.io/KRV/ (GitHub Pages, ветка `landing-v1`, обновляется после каждого пуша).

Статичный сайт: `index.html` + `assets/`. Сборка не нужна — локально достаточно `python -m http.server 5173`.

## Позиционирование

- **Зачем приходят:** за фигурой.
- **Почему раньше не получалось:** не из-за силы воли, а из-за усталости каждый день решать «что поесть» → срывы.
- **Что продаём:** систему, которая убирает это решение: 2 часа у плиты — еда на 3 дня, КБЖУ и список продуктов готовы.
- **Главное сообщение:** «Худеть вкусно, готовить раз в три дня».

## Сценарий страницы (каждый блок = один экран)

1. Hero — видео с затемнением, одна CTA.
2. «Представь…» — карточка по центру, вокруг всплывают карточки-преимущества (приём Serein).
3. «Дело не в силе воли» — боль и переворот.
4. «Как это работает» — 4 экрана сменяют друг друга целиком, с блюр-появлением текста.
5. «Почему на этом худеют» — шахматка 4×2 (Loiseau), на телефоне 2×2.
6. Калорийность 1400–1800 — реальные фото рационов.
7. Лента «паста ✦ пицца… / не диета» (Sweet Tape).
8. «Что внутри» — меню ресторана, фото за курсором.
9. Кристина — история, −13 кг / −9 кг у Макса.
10. Отзывы — коллаж на скотче, карточки двигаются.
11. Тарифы — на телефоне вкладками.
12. Вопросы. 13. Финал + подвал.

## Механики

- **CTA-док:** кнопка появляется в hero и при скролле плавно оседает внизу экрана; по нажатию раскрывается как iOS-виджет с тарифами. На тарифах прячется.
- **Меню:** в шапке только логотип и кнопка; на десктопе меню вырастает из шапки по наведению.
- **Мобильные модалки:** боттом-шиты с ручкой, закрываются свайпом вниз; крестик закреплён справа сверху.
- **Прелоадер:** минимум 2 с, ждёт шрифты, постер и видео.
- **Типограф (JS):** неразрывные пробелы после предлогов, союзов и частиц, перед тире, между числом и единицей; последнее слово заголовка не остаётся одно.
- **Анимации:** GSAP + ScrollTrigger, Lenis — лежат в `assets/vendor`. Учитывается `prefers-reduced-motion`.

## Дизайн-система

- **Шрифты:** Noto Serif Display 400 / ширина 62.5% — замена Country Club у Serein (у него нет кириллицы); текст Geist; заметки Caveat.
- **Цвета:** молочный `#F7F5EC`, крем `#EEE9DA`, глубокий оливковый `#2E3520`, оливковый `#5E6A3A`, шалфей `#CBD0B2`, лайм `#DCE7A9`, терракота `#96583F`.
- **Логотип:** стопка из трёх контейнеров с ростком + курсивное «что поесть» (символ `#mark` в `index.html`, `assets/img/favicon.svg`).

## SEO

title/description, canonical, Open Graph + Twitter (`assets/img/og-image.jpg`, 1200×630), фавиконки и `site.webmanifest`, `robots.txt`, `sitemap.xml`, JSON-LD (`WebSite`, `Person`, `Product` с двумя `Offer`, `FAQPage`). Один `h1`, по `h2` на блок, у всех картинок есть `alt`.
Когда появится свой домен, замените `https://sergeykutedesign.github.io/KRV/` в `index.html`, `robots.txt` и `sitemap.xml`.

## Что ещё нужно от Кристины

- фото «до/после» или анализы участниц — под них можно добавить блок результатов между «Почему худеют» и «Кристиной»;
- больше отзывов (скрины) — карточки добавляются в `.board`.
