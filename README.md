## Позиционирование

**Зачем приходят:** за фигурой — похудеть и нравиться себе в зеркале.
**Почему не получалось раньше:** не из-за слабой силы воли, а из-за усталости решать «что поесть» каждый день → срывы, доставка, «начну с понедельника».
**Что продаём:** систему, которая убирает ежедневные решения о еде. Экономия времени, вкус и рассчитанное КБЖУ — не цель, а механизм и преимущества, благодаря которым результат держится.

> Главное сообщение: **«Худеть вкусно.»** + **«Готовишь раз — ешь три дня.»**
> Логическая цепочка сайта: *минус вопрос «что поесть» → минус срывы → минус килограммы.*

Доказательства: Кристина −13 кг, муж Макс −9 кг (раньше не готовил вообще), 4 500+ участниц, 58+ рационов, 210+ рецептов, 100+ отзывов в актуальном.
Отстройка от «очередного канала с рецептами»: не количество рецептов, а готовая система (меню → список покупок → видео-последовательность → контейнеры на 3 дня). В рационах есть паста, пицца и шоколадки — «не грудка с гречкой».

## Дизайн-система

- **Шрифты:** Noto Serif Display в узком светлом начертании (`font-stretch: 62.5%`, `font-weight: 300`) — максимально близкая к Country Club (шрифт Serein) замена с кириллицей; у Country Club кириллицы нет. Текст — Geist (как у Serein). Рукописный — Caveat (заметки).
- **Цвета:** молочный `#F7F5EC`, крем `#EEE9DA`, глубокий оливковый `#2E3520`, оливковый `#5E6A3A`, шалфей `#CBD0B2`, лайм `#DCE7A9`, терракота CTA `#96583F`, чернила `#1D1B14`.
- **Анимации:** GSAP + ScrollTrigger, плавный скролл Lenis (лежат в `assets/vendor`, без CDN). Учитывается `prefers-reduced-motion`.
